Install & configure Ducktape CLI

Ducktape lets you sync, patch and ship config across environments from your terminal.

Prerequisites

Node.js 20 or newer. Older versions fail with ERR_UNSUPPORTED_ENGINE.

1. Install

  • Linux: curl -fsSL https://get.ducktape.dev | sh
  • macOS: brew install ducktape/tap/ducktape
  • Windows: winget install Ducktape.CLI

2. Authenticate

Create a token in the dashboard and set it as the DUCKTAPE_TOKEN environment variable. Since v3 the CLI ignores tokens saved in ~/.ducktaperc.

# Linux/macOS
export DUCKTAPE_TOKEN=your-token
# Windows PowerShell
$env:DUCKTAPE_TOKEN = "your-token"

3. Connect to your workspace

ducktape login --workspace <name> --region eu-west

Regions: eu-west, us-east. Use the region shown in your dashboard.

4. Verify

Run ducktape doctor. All checks should be green. If the token check fails, confirm DUCKTAPE_TOKEN is set in the current shell.
