Deploy a static site to Pondhost

Pondhost serves static sites from a global edge network. Works with Vite, Next.js static export, Hugo and more.

1. Install the CLI

npm install -g pondhost

2. Configure your project

Add a pond.toml at your project root. Pondhost serves ./public by default; set publish_dir if your build outputs elsewhere (Vite uses dist).

[site]
name = "my-site"
publish_dir = "dist"

[build]
command = "npm run build"

3. Link, then deploy

Run pond link once before your first deploy, otherwise the deploy creates a duplicate project.

pond link
pond deploy --prod

4. Add a custom domain

pond domains add docs.example.com

Then create a CNAME record pointing your domain to edge.pondhost.net. HTTPS is issued automatically within ~5 minutes.

5. Verify

Run pond status; the domain should show active and tls: issued.
